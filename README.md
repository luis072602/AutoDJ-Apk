# AutoDJ

Mezcla automática de música para Android: busca tus canciones y AutoDJ las mezcla al ritmo de cada una.

Este repositorio solo guarda las versiones para descargar; el código de la app es privado.

## Descargar

1. En el teléfono, descarga **[AutoDJ.apk](https://github.com/luis072602/AutoDJ-Apk/releases/latest/download/AutoDJ.apk)**.
2. Ábrelo. Android pedirá permiso para «instalar apps desconocidas» desde el navegador o el gestor de archivos: acéptalo.
3. Para actualizar no hace falta volver aquí: la app avisa cuando hay una versión nueva y se instala encima de la anterior.

Requiere Android 8.0 o superior.
